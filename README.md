# Tornería Mecánica y Soldaduras - Landing Page

Sitio web profesional desarrollado para **Tormecanica**, empresa líder en servicios de tornería y soldaduras especializadas ubicada en Cerro Alto, Los Álamos, Región del Biobío.

## 🚀 Despliegue
El sitio se encuentra activo y puede ser visitado en:
**[https://nanculefservice.github.io/tormecanica/](https://nanculefservice.github.io/tormecanica/)**

## 🛠️ Sobre el Proyecto
Esta landing page ha sido diseñada para centralizar la presencia digital del taller, facilitando la cotización de servicios industriales y la visualización de trabajos realizados.

### Características principales:
- **Diseño Responsive:** Optimizado para dispositivos móviles y escritorio.
- **Enfoque en Conversión:** Botones directos de contacto y acceso rápido a WhatsApp para cotizaciones.
- **Secciones Detalladas:**
    - Inicio con propuesta de valor.
    - Catálogo de servicios técnicos.
    - Sectores industriales atendidos.
    - Galería de proyectos reales.
    - Formas de contacto y ubicación física.

## 🔧 Servicios Destacados
- **Tornería Convencional:** Fabricación de piezas con alta precisión (ejes, bujes, engranajes).
- **Soldadura Especializada:** Procesos MIG, TIG y arco en diversos materiales.
- **Trabajos en Terreno:** Soporte de emergencia 24/7 para faenas industriales.
- **Fabricación:** Réplicas por muestra física o según planos técnicos.

## 🏗️ Sectores de Impacto
El taller entrega soluciones a industrias clave de la zona:
- Forestal y Agrícola.
- Construcción y Maquinaria Pesada.
- Automotriz, Naval y Electromecánica.
